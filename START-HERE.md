# RESET.EXE — Start Here

## What this activity is

RESET.EXE: The Glitched Phone is a whole-class digital investigation. Students recover one ordinary day from Jordan's phone, compare evidence, challenge the advice issued by RESET.EXE, and rebuild the system's decision model.

The activity is mystery-first. Students are not asked to disclose personal experiences.

## Normal classroom setup

1. Double-click `RESET-EXE-Launcher.cmd`.
2. The facilitator screen opens automatically.
3. Click **OPEN STUDENT SCREEN**.
4. Move the student window to the TV/projector.
5. Open **Display & advanced controls** and run **DISPLAY CHECK** if needed.
6. Fullscreen the student display.
7. Confirm the facilitator shows **Connected**.
8. Start the timer if you want one, then begin.

## How to run it

Use the facilitator panel on the right for each scene:

- **SAY** — short wording to introduce the scene.
- **LISTEN FOR** — the reasoning or answer the class should reach.
- **IF THEY'RE STUCK** — the three-step hint ladder.

For harder evidence scenes, use **20s SCAN** before discussion. One student can operate the screen while the class tells them what to select.

## Timing

Target: **25–35 minutes**.

If time is tight, use **REVEAL** or **SKIP** rather than letting a puzzle stall. Skipping restores the evidence needed later.

## The core idea

RESET.EXE's advice is not deliberately bad. Most recommendations sound reasonable in isolation. The investigation shows why advice can fail when it ignores context, priority, basic needs, whether a strategy is still helping, or whether something can wait.

Final line: **Not every problem needs fixing at once.**
